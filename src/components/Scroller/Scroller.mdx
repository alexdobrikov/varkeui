# Scroller

Горизонтальная лента: ряд плиток, карточек или чего угодно, что не помещается по ширине. На телефоне листается пальцем с прилипанием к элементам, на десктопе — стрелками, колесом с Shift, трекпадом и клавиатурой.

```tsx
import { Scroller } from 'varkeui';
```

<Canvas of={Stories.Hub} />

## Как работает

- Каждый ребёнок оборачивается в элемент ленты, ширину задаёт сам ребёнок: `TileButton` — свою, `BentoCard` — через `style`.
- `snap` прилипает к началу элемента после прокрутки.
- `fade` плавно затухает по тем краям, за которыми есть ещё элементы.
- Стрелки появляются при наведении мышью и только в ту сторону, куда есть что листать. Клик прокручивает примерно на ширину видимой области. На сенсорных экранах стрелок нет — там листают пальцем. `controls="always"` показывает их всегда, `controls="never"` убирает.
- Лента получает фокус с клавиатуры: ←/→ прокручивают, Home и End переносят в начало и в конец.

## На всю ширину экрана

Типичный мобильный приём: заголовок и первый элемент стоят по сетке страницы, а лента прокручивается до самого края экрана. Уберите горизонтальный отступ у контейнера и передайте его в `inset`.

<Canvas of={Stories.FullBleed} />

```tsx
<div style={{ marginInline: -16 }}>
  <Scroller aria-label="Explore" inset={16}>
    …
  </Scroller>
</div>
```

## Пропсы

Остальные пропсы — `aria-label`, `onScroll`, `id` и т. п. — уходят на прокручиваемый элемент, `className` и `style` — на корневой.

## Доступность

- Дайте ленте `aria-label`: она получает фокус, и скринридеру нужно её назвать.
- Стрелки — для мыши и не попадают в порядок табуляции. С клавиатуры лента листается сама, а фокус внутри неё переходит по элементам.
- `prefers-reduced-motion` отключает плавную прокрутку.

## CSS-переменные

| Переменная                   | По умолчанию                                                                                         |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| `--vui-scroller-gap`         | 16px                                                                                                 |
| `--vui-scroller-inset`       | 0                                                                                                    |
| `--vui-scroller-fade`        | 48px — ширина затухания                                                                              |
| `--vui-scroller-button-size` | 40px                                                                                                 |
| `--vui-scroller-button-top`  | 50% — вертикальная позиция стрелок. Для плиток с подписью удобнее середина картинки, например `80px` |
| `--vui-scroller-bleed-y`     | 8px — запас сверху и снизу, чтобы не обрезались рамка фокуса и выступающие бейджи                    |
