# Chip

Компактные «таблетки»: фильтры, категории, теги. Бывают статичными, выбираемыми и удаляемыми.

```tsx
import { Chip } from 'varkeui';
```

<Canvas of={Stories.MultipleChoice} />

## Выбор

С `selected` чип становится переключателем: выбранный инвертируется, скринридер слышит «нажато». Состоянием управляете вы — так один и тот же чип подходит и для выбора одного варианта, и для нескольких.

```tsx
const [active, setActive] = useState('All');

{
  categories.map((category) => (
    <Chip
      key={category}
      selected={active === category}
      onSelectedChange={() => setActive(category)}
    >
      {category}
    </Chip>
  ));
}
```

Длинный ряд кладите в [Scroller](?path=/docs/components-scroller--docs) — на телефоне он листается пальцем.

## Удаление

`onRemove` добавляет крестик. Его подпись для скринридеров собирается из `removeLabel` и текста чипа: «Remove Kazan».

## Доступность

- Выбираемый чип — `<button aria-pressed>`, кнопка-действие — обычный `<button>`, статичный — просто текст.
- Крестик — отдельная кнопка со своей подписью, поэтому его можно нажать с клавиатуры, не выбирая сам чип.
