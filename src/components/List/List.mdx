# List и ListItem

Пункт списка: иконка слева, заголовок и подзаголовок, справа — необязательный слот. Подходит для онбординга, экранов настроек, меню и описаний возможностей.

```tsx
import { List, ListItem } from 'varkeui';
```

<Canvas of={Stories.Onboarding} />

## Статичный или кликабельный

Без `onClick` и `href` пункт — обычный блок. С `onClick` он становится кнопкой, с `href` — ссылкой, подсвечивается при наведении и получает фокус с клавиатуры. Слот `after` — для стрелки, переключателя или счётчика.

`List` собирает пункты в `<ul>`, а `dividers` добавляет между ними разделители. Разделитель начинается от текста, а не от края, и прячется рядом с подсвеченным пунктом, чтобы не резать плашку.

## Строка-переключатель и свои ссылки

`as` меняет корневой элемент. `as="label"` делает всю строку переключателем для `Switch` в `after` — подробнее на странице [Switch](?path=/docs/components-switch--docs). `as={Link}` превращает пункт в ссылку роутера.

## Размеры

`sm` — для плотных меню, `md` — для настроек, `lg` — для онбординга и промо-блоков.

## Доступность

- `List` — это `<ul>`, каждый пункт оборачивается в `<li>`.
- Доступное имя кликабельного пункта складывается из заголовка и подзаголовка.
- Иконки по умолчанию декоративные. Если иконка несёт смысл, передайте `iconAlt`.

## CSS-переменные

| Переменная                                                    | По умолчанию                   |
| ------------------------------------------------------------- | ------------------------------ |
| `--vui-list-item-icon-size`                                   | 32px / 48px / 72px по `size`   |
| `--vui-list-item-gap`                                         | 12px / 16px / 28px             |
| `--vui-list-item-padding-y`                                   | 8px / 12px / 24px              |
| `--vui-list-item-padding-x`                                   | 0, у кликабельного пункта 12px |
| `--vui-list-item-radius`                                      | Скругление подсветки           |
| `--vui-list-item-title-size`, `--vui-list-item-subtitle-size` | Размеры шрифта                 |
