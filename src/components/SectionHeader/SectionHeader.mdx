# SectionHeader

Заголовок секции. Со ссылкой получает стрелку «›» и ведёт на полный список раздела, справа можно поставить действие или счётчик.

```tsx
import { SectionHeader } from 'varkeui';
```

<Canvas of={Stories.Variants} />

## Ссылка

`href` делает заголовок ссылкой, `onClick` — кнопкой. Стрелка при наведении слегка сдвигается вправо. Сам тег заголовка остаётся на месте, поэтому структура страницы для скринридеров не меняется.

Для роутеров передайте компонент ссылки в `linkAs`, а его пропсы — в `linkProps`:

```tsx
import { Link } from 'react-router';

<SectionHeader title="Collections" linkAs={Link} linkProps={{ to: '/collections' }} />;
```

```tsx
import Link from 'next/link';

<SectionHeader title="Collections" linkAs={Link} href="/collections" />;
```

<Canvas of={Stories.WithRouterLink} />

## Счётчик

`count` ставит число сразу после заголовка, приглушённым цветом: «Notifications 30». Он входит в заголовок и в ссылку, поэтому скринридер читает их вместе. Принимает число или готовую строку — сокращать большие числа вроде `1.2K` удобнее заранее. Цифры моноширинные, и заголовок не дёргается, когда число меняется.

<Canvas of={Stories.WithCount} />

```tsx
<SectionHeader title="Notifications" count={30} />
```

Красный бейдж с непрочитанными — другое: передайте [Badge](?path=/docs/components-badge--docs) в `action`.

## Размеры и уровень заголовка

20, 24 и 32 px. Размер не связан с тегом: `headingAs` выбирает уровень `h1`–`h6` под структуру страницы, по умолчанию `h2`.
