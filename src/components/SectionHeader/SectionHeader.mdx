# SectionHeader

Заголовок секции. Со ссылкой получает стрелку «›» и ведёт на полный список раздела, справа можно поставить действие или счётчик.

```tsx
import { SectionHeader } from 'varkeui';
```

<Canvas of={Stories.Variants} />

## Ссылка

`href` делает заголовок ссылкой, `onClick` — кнопкой. Стрелка при наведении слегка сдвигается вправо. Сам тег заголовка остаётся на месте, поэтому структура страницы для скринридеров не меняется.

Для роутеров передайте компонент ссылки в `linkAs`, а его пропсы — в `linkProps`:

```tsx
import { Link } from 'react-router';

<SectionHeader title="Collections" linkAs={Link} linkProps={{ to: '/collections' }} />;
```

```tsx
import Link from 'next/link';

<SectionHeader title="Collections" linkAs={Link} href="/collections" />;
```

<Canvas of={Stories.WithRouterLink} />

## Подзаголовок и кнопка

`action` — слот справа: кнопка, переключатель, бейдж. Он выравнивается по центру строки заголовка, а не всего блока, поэтому с подзаголовком кнопка остаётся на одной линии с заголовком. Подзаголовок идёт ниже на всю ширину.

<Canvas of={Stories.WithSubtitleAndAction} />

```tsx
<SectionHeader
  title="Lessons"
  subtitle="Your own lessons and the open ones from the library"
  action={
    <Button size="sm" startIcon={<PlusIcon />}>
      New lesson
    </Button>
  }
/>
```

## Счётчик

`count` ставит число сразу после заголовка, приглушённым цветом: «Notifications 30». Он входит в заголовок и в ссылку, поэтому скринридер читает их вместе. Принимает число или готовую строку — сокращать большие числа вроде `1.2K` удобнее заранее. Цифры моноширинные, и заголовок не дёргается, когда число меняется.

<Canvas of={Stories.WithCount} />

```tsx
<SectionHeader title="Notifications" count={30} />
```

### Анимация счётчика

Числовой `count` набегает: при появлении — от нуля, при смене — от прежнего значения, около 0,7 с с замедлением к концу. Прерванная анимация продолжается от того числа, на котором остановилась. Скринридер всё это время читает конечное число, а не каждый кадр.

Анимации нет у строк (`"2 of 5"`, `"1.2K"`) и дробных чисел, при `prefers-reduced-motion` и при гидрации: если заголовок пришёл с сервера, в HTML уже верное число, и откат к нулю выглядел бы как сбой. От нуля считает только то, что появилось в браузере после загрузки, например после запроса данных. Выключить: `animateCount={false}`.

<Canvas of={Stories.AnimatedCount} />

```tsx
<SectionHeader title="Ready decks" count={decks.length} />
<SectionHeader title="Static" count={30} animateCount={false} />
```

Красный бейдж с непрочитанными — другое: передайте [Badge](?path=/docs/components-badge--docs) в `action`.

## Размеры и уровень заголовка

15, 20, 24 и 32 px. `xs` повторяет подпись поля (15 px, начертание 500) — для заголовка группы внутри формы или модалки, например «Ученики 2 из 5» над списком галочек. Размер не связан с тегом: `headingAs` выбирает уровень `h1`–`h6` под структуру страницы, по умолчанию `h2`.
