# StatCard

Карточка с одним крупным значением и подписями вокруг: время, температура, сумма, счётчик. Подходит для блоков «что дальше» и сводок: ближайшая запись, прогноз, рейс, баланс, активность за день. `StatRow` ставит в ряд главную карточку и несколько узких рядом.

```tsx
import { StatCard, StatRow } from 'varkeui';
```

<Canvas of={Stories.Playground} />

```tsx
<StatRow>
  <StatCard
    featured
    color="#a0195a"
    label="Next lesson"
    tag="tomorrow"
    caption="Saturday"
    title="October 31"
    value="14:00"
    onClick={openCalendarMenu}
  />
  <StatCard color="#a0195a" tag="Saturday" caption="November 7" value="14:00" />
  <StatCard color="#a0195a" tag="Saturday" caption="November 14" value="14:00" />
</StatRow>
```

## Слоты

- `label` — подпись слева сверху: о чём карточка.
- `tag` — плашка справа сверху: относительное время, изменение, день недели.
- `caption` и `title` — пояснение к значению: приглушённая строка и строка покрупнее.
- `value` — само значение. Цифры моноширинные, так что соседние карточки не прыгают при обновлении.

Все слоты необязательные, но без `value` карточка теряет смысл.

## Главная и обычные карточки

`featured` раскладывает карточку горизонтально: пояснение слева, значение справа, крупнее (48 px, в карточке шире 480 px — 60 px). Обычная карточка — колонка: плашка сверху, значение снизу. `align` прижимает её текст к правому краю (по умолчанию) или к левому.

## Цвет

Без `color` карточки берут фон `surface` текущей темы. С `color` главная карточка заливается им на 55%, обычная — на 25%, а плашка обычной — на 70%. Цвет смешивается с прозрачным, поэтому подстраивается под фон страницы.

<Canvas of={Stories.Tints} />

## На мобильном и на десктопе

Раскладка зависит от ширины ряда, а не экрана (container queries). Уже 640 px главная карточка занимает всю строку, остальные встают по две под ней. Шире — всё в одну строку: главная тянется, остальные шириной `itemWidth` (176 px). Если главной нет, карточки делят строку поровну.

## Кликабельная карточка

С `onClick` карточка становится кнопкой, с `href` — ссылкой, `as` подставляет свой компонент, например `Link` из роутера. Ref и пропсы пробрасываются на корень, поэтому карточку можно отдать триггером в выпадающее меню: «добавить в календарь», «подробнее о рейсе».

## Доступность

- Кликабельная карточка — одна кнопка или ссылка, её имя для скринридера складывается из всего текста. Если оно выходит длинным, задайте короткое через `aria-label`.
- Внутри кликабельной карточки не должно быть других кнопок и ссылок.
- Значение без единиц («17°», «512») поясните в `caption` или `label`, чтобы оно читалось и без картинки.

## CSS-переменные

| Переменная                  | По умолчанию                       |
| --------------------------- | ---------------------------------- |
| `--vui-stat-bg`             | `surface` или `color` на 55 / 25%  |
| `--vui-stat-tag-bg`         | Текст на 12–15% или `color` на 70% |
| `--vui-stat-padding`        | 24px                               |
| `--vui-stat-radius`         | 28px                               |
| `--vui-stat-min-height`     | 176px у главной, 128px у обычной   |
| `--vui-stat-value-size`     | 48px у главной, 36px у обычной     |
| `--vui-stat-row-item-width` | 176px                              |
| `--vui-stat-row-gap`        | 16px                               |
