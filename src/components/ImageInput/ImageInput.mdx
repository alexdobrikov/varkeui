# ImageInput

Компактная область загрузки картинки с пунктирной рамкой: иконка, инструкция, допустимые форматы и стандартные кнопки библиотеки. Подходит для обложек и иллюстраций. Файл можно выбрать или перетащить; выбранная картинка отображается компактным превью. На широком поле превью, подпись и кнопки стоят в строку; в узком кнопки переносятся ниже. Прогресс занимает отдельную тонкую строку.

```tsx
import { ImageInput } from 'varkeui';
```

## Загрузка

Компонент не загружает файл сам: `onFileSelect` отдаёт выбранный `File`, а вы загружаете его куда нужно и передаёте адрес в `value`. Пока идёт загрузка, `loading` блокирует повторный выбор. Передавайте реальный `progress` от 0 до 100, чтобы показать процент и полосу; до начала передачи отображается 0%. Текст процента настраивается через `progressLabel`. `onRemove` добавляет крестик для удаления.

```tsx
<ImageInput
  block
  label="Cover"
  value={url}
  loading={uploading}
  progress={percent}
  progressLabel={(value) => `${value}%`}
  onFileSelect={async (file) => setUrl(await upload(file))}
  onRemove={() => setUrl(null)}
/>
```

## Буфер и WebP

<Canvas of={Stories.AllSources} />

`maxSize` задаёт лимит исходного файла в байтах, проверяемый до декодирования и загрузки.
`webp` включает локальную конвертацию: длинная сторона до 2560 px, качество 0.82;
настройки можно передать объектом `{ maxDimension, quality }`. Анимированные файлы
превращаются в статичное превью. Если браузер не умеет кодировать WebP (Safari), подходящий
по размеру оригинал уходит как есть, а слишком большой уменьшается в JPEG (PNG для PNG и GIF).
`prepareImage` экспортируется отдельно для других загрузчиков.

`allowPaste` добавляет кнопку чтения буфера и вставку Ctrl/Cmd+V на странице,
когда фокус вне input/textarea/select, contenteditable и текстовых редакторов.
Кнопка запрашивает разрешение браузера; клавиатурная вставка работает через paste event
без отдельного запроса Clipboard API. `dropLabel` задаёт основную инструкцию,
`placeholder` — форматы/лимит, `pasteHint` — подсказку сочетания клавиш.

Если загрузчиков несколько, вставка выбирает последний использованный видимый
компонент; до первого взаимодействия — первый видимый в порядке документа.
Скрытые компоненты и область за пределами экрана не выбираются. Открытый modal
ограничивает получателя компонентами внутри него; фон не получает вставку.
Повторная вставка во время загрузки не переключается на соседнее поле.

Ввод ссылок на сторонние ресурсы не поддерживается. Картинки выбираются файлом, перетаскиванием или из буфера.

Асинхронный `onFileSelect` удерживает состояние загрузки до завершения promise.
Ошибка снимает загрузку, показывается в поле и передаётся в `onError`. Тексты
валидации можно перевести через `messages` (`size`, `type`, `processing`, `clipboard`).

## CSS-переменные

| Переменная                 | По умолчанию               |
| -------------------------- | -------------------------- |
| `--vui-image-input-height` | 224px — минимальная высота |
| `--vui-image-input-radius` | 20px                       |
| `--vui-image-input-inset`  | 24px — отступ содержимого  |
| `--vui-image-input-bg`     | `transparent`              |

`labelHidden` оставляет доступную подпись для выбора файла, когда видимый заголовок уже показан над областью.
