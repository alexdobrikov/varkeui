# ImageInput

Поле для картинки: обложка, аватар, иллюстрация. Выглядит как [Input](?path=/docs/components-input--docs) — та же подпись, поверхность и подсказка, — слева превью, справа кнопка. Файл можно перетащить прямо на поле.

```tsx
import { ImageInput } from 'varkeui';
```

<Canvas of={Stories.WithPreview} />

## Загрузка

Компонент не загружает файл сам: `onFileSelect` отдаёт выбранный `File`, а вы загружаете его куда нужно и передаёте адрес в `value`. Пока идёт загрузка, `loading` показывает крутилку вместо кнопки. `onRemove` добавляет крестик для удаления.

```tsx
<ImageInput
  block
  label="Cover"
  value={url}
  loading={uploading}
  onFileSelect={async (file) => setUrl(await upload(file))}
  onRemove={() => setUrl(null)}
/>
```

## Буфер, ссылка и WebP

<Canvas of={Stories.AllSources} />

`maxSize` задаёт лимит исходного файла в байтах, проверяемый до декодирования и загрузки.
`webp` включает локальную конвертацию: длинная сторона до 2560 px, качество 0.82;
настройки можно передать объектом `{ maxDimension, quality }`. Анимированные файлы
превращаются в статичное превью. `prepareImage` экспортируется отдельно для других загрузчиков.

`allowPaste` добавляет вставку Ctrl/Cmd+V в поле и кнопку чтения буфера. Кнопка
запрашивает разрешение браузера; вставка клавиатурой доступна и без Clipboard API.
`onUrlSelect` добавляет поле для http/https-ссылки. Ссылки не скачиваются и не конвертируются.

Асинхронный `onFileSelect` удерживает состояние загрузки до завершения promise.
Ошибка снимает загрузку, показывается в поле и передаётся в `onError`. Тексты
валидации можно перевести через `messages` (`size`, `type`, `processing`, `clipboard`, `url`).
