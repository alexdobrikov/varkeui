# ImageInput

Поле для картинки: обложка, аватар, иллюстрация. Выглядит как [Input](?path=/docs/components-input--docs) — та же подпись, поверхность и подсказка, — слева превью, справа кнопка. Файл можно перетащить прямо на поле.

```tsx
import { ImageInput } from 'varkeui';
```

<Canvas of={Stories.WithPreview} />

## Загрузка

Компонент не загружает файл сам: `onFileSelect` отдаёт выбранный `File`, а вы загружаете его куда нужно и передаёте адрес в `value`. Пока идёт загрузка, `loading` показывает крутилку вместо кнопки. `onRemove` добавляет крестик для удаления.

```tsx
<ImageInput
  block
  label="Cover"
  value={url}
  loading={uploading}
  onFileSelect={async (file) => setUrl(await upload(file))}
  onRemove={() => setUrl(null)}
/>
```
