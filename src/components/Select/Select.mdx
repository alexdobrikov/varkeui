# Select

Нативный выпадающий список. Меню, клавиатура и выбор на мобильных устройствах остаются системными.
Поле использует размеры, варианты, скругления и состояния Input: sm 40 px, md 48 px, lg 56 px.
Передавайте option через children, label для доступного имени, hint или error для пояснения.
value, defaultValue, onChange, name, required, disabled и ref передаются нативному select.
