# PromoCarousel

Карусель промо-карточек: слайды сменяются по таймеру, полоска на активной точке показывает, сколько осталось до следующего. На телефоне листается свайпом, на компьютере — стрелками по бокам, точками и клавиатурой.

```tsx
import { Button, PromoCard, PromoCarousel } from 'varkeui';
```

<Canvas of={Stories.Playground} />

```tsx
<PromoCarousel aria-label="Offers" interval={6000}>
  <PromoCard
    title="Reach more readers"
    description="Boost your posts and find a new audience"
    image="/img/rocket.png"
    action={<Button size="lg">Try it</Button>}
  />
  <PromoCard tone="light" title="Weekend sale" action={<Button size="lg">See deals</Button>} />
</PromoCarousel>
```

Внутрь можно класть любые элементы, но удобнее всего [PromoCard](?path=/docs/components-promocard--docs). Слайды выравниваются по самому высокому, а кнопки карточек встают на одну линию.

## Автопрокрутка

`interval` задаёт, сколько миллисекунд показывается слайд, по умолчанию 6 секунд. После последнего слайда карусель возвращается к первому. Таймер ставится на паузу, пока:

- на карусель наведена мышь;
- фокус с клавиатуры на точках, стрелках или кнопке внутри слайда;
- вкладка браузера скрыта.

При `prefers-reduced-motion` карусель сама не листается. `autoPlay={false}` выключает автопрокрутку совсем.

## Стопка и точки

По умолчанию под каруселью выглядывает край следующей карточки, и точки лежат на нём. `stacked={false}` убирает стопку, точки остаются под слайдами.

<Canvas of={Stories.Flat} />

## На десктопе

Стрелки показываются только на устройствах с мышью и наполовину выходят за края карусели. Оставьте по бокам 22 px свободного места. Ширина карточки внутри меняет и её раскладку: в широкой карусели кнопки встают под текст.

## Доступность

- Корень — `region` с `aria-roledescription="carousel"`. Передайте `aria-label`, например `Offers`.
- Каждый слайд — `group` с подписью `2 of 5`, у точки та же подпись и `aria-current` на активной. Текст подписи меняется через `slideLabel`, подписи стрелок — через `previousLabel` и `nextLabel`.
- Когда фокус на точках или стрелках, ← и → листают слайды.
- Автопрокрутка останавливается при наведении и фокусе, чтобы текст успели прочитать.
- `imageBleed` у карточек внутри карусели обрезается: слайды прокручиваются в контейнере с `overflow`.

## CSS-переменные

| Переменная                   | По умолчанию                                 |
| ---------------------------- | -------------------------------------------- |
| `--vui-carousel-gap`         | 16px — между слайдами при прокрутке          |
| `--vui-carousel-arrow-size`  | 44px                                         |
| `--vui-carousel-deck-inset`  | 24px — насколько стопка уже карусели с боков |
| `--vui-carousel-deck-radius` | 24px                                         |
