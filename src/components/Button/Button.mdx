# Button и IconButton

Кнопки для действий: от главного «Сохранить» до входа через сторонний аккаунт. `IconButton` — квадратная кнопка с одной иконкой.

```tsx
import { Button, IconButton } from 'varkeui';
```

<Canvas of={Stories.Variants} />

## Варианты

| Вариант     | Когда использовать                                                        |
| ----------- | ------------------------------------------------------------------------- |
| `primary`   | Главное действие на экране. Обычно одно                                   |
| `secondary` | Второстепенные действия рядом с главным                                   |
| `outline`   | Альтернатива `secondary`, когда кнопка стоит на цветном фоне или карточке |
| `ghost`     | Действия низкого приоритета, тулбары, «Отмена»                            |
| `danger`    | Удаление и другие необратимые действия                                    |

## Иконки

`startIcon` ставит иконку перед текстом, `endIcon` — после. Иконка берёт цвет текста кнопки и подстраивается под размер.

<Canvas of={Stories.WithIcons} />

## Размеры

40, 48 и 56 px — как у `Input`, поэтому поле и кнопка одного размера стоят в ряд ровно.

<Canvas of={Stories.Sizes} />

## Кнопки входа

Кнопка на всю ширину (`block`) с логотипом сервиса в `startIcon`. Логотип можно передать SVG-компонентом или `<img>`.

<Canvas of={Stories.SignIn} />

```tsx
<Button variant="secondary" size="lg" block startIcon={<img src={logo} alt="" />}>
  Sign in with Orbit ID
</Button>
```

## Загрузка

`loading` показывает спиннер и блокирует кнопку. Текст остаётся в разметке, поэтому ширина кнопки не меняется, а скринридер продолжает читать подпись. Выставляется `aria-busy`.

<Canvas of={Stories.Loading} />

## IconButton

Квадратная кнопка с одной иконкой. Текста на ней нет, поэтому `aria-label` обязателен — TypeScript не даст его забыть. По умолчанию вариант `secondary`.

<Canvas of={Stories.IconButtons} />

```tsx
<IconButton aria-label="Delete" icon={<TrashIcon />} variant="danger" onClick={remove} />
```

## Ссылки

С `href` кнопка рендерится ссылкой `<a>`. Для навигации без перезагрузки передайте компонент ссылки роутера в `as`:

```tsx
import { Link } from 'react-router';

<Button as={Link} to="/settings" variant="secondary">
  Settings
</Button>;
```

## Доступность

- Кнопки — настоящие `<button>`, ссылки — настоящие `<a>`: работают с клавиатуры и скринридерами без доработок.
- `disabled` у ссылки превращается в `aria-disabled` и убирает её из порядка табуляции.
- Иконки внутри кнопок декоративные: доступное имя берётся из текста или `aria-label`.

## CSS-переменные

| Переменная                                 | По умолчанию                 |
| ------------------------------------------ | ---------------------------- |
| `--vui-button-height`                      | 40px / 48px / 56px по `size` |
| `--vui-button-padding-x`                   | 16px / 20px / 24px           |
| `--vui-button-radius`                      | 12px / 16px / 20px           |
| `--vui-button-gap`                         | 6px / 8px / 10px             |
| `--vui-button-font-size`                   | 15px / 16px / 17px           |
| `--vui-button-icon-size`                   | 20px / 22px / 24px           |
| `--vui-button-bg`, `--vui-button-bg-hover` | Фон и фон при наведении      |
| `--vui-button-color`                       | Цвет текста и иконок         |
| `--vui-button-border-color`                | Цвет обводки                 |
