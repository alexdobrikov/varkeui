# Modal

Модальное окно: подтверждение, короткая форма, выбор из списка. Построено на нативном `<dialog>`: окно в верхнем слое, фокус остаётся внутри, страница под ним недоступна и не прокручивается, Esc закрывает.

```tsx
import { Modal } from 'varkeui';
```

<Canvas of={Stories.Playground} />

## Открытие и закрытие

Окно управляется снаружи: `open` — показать, `onClose` — пользователь хочет закрыть (крестик, Esc, клик по фону). Закрыть — поставить `open={false}`. Так можно не закрывать окно, пока идёт сохранение. Клик по фону выключается `closeOnBackdrop={false}`.

```tsx
const [open, setOpen] = useState(false);

<Modal open={open} onClose={() => setOpen(false)} title="Delete lesson?" actions={…} />;
```

## Форма

`children` — содержимое окна: поля встают столбиком с отступом 20 px, длинная форма прокручивается внутри, шапка и кнопки остаются на месте. `actions` — кнопки внизу, в ряд равной ширины. `icon` — эмодзи или картинка над заголовком, с ней шапка центрируется.
